# 讯飞杯报名系统项目进程

> 本文档在每个可验收工作项完成后更新，记录已完成结果、验证方式与后续事项。

## 项目范围

- 赛事：河南工业大学第三届“讯飞杯”AI+创新应用大赛。
- 本期：学生登录、报名草稿、正式报名、报名表 PDF 预览/下载、历史记录。
- 非本期：管理员审核、教师端、材料上传、在线评审、二维码与校验码。

### 阶段 1 验收目标

1. 当前仓库可作为 RuoYi-Vue 的开发基础工程，前端生产构建通过。
2. 可在浏览器打开讯飞杯专属登录页：`http://127.0.0.1:5173/#/xfc/login`（本次开发会话中本地服务保持运行）。
3. 登录页明确使用现有竞赛服务平台账号，不提供新账号注册入口。
4. 阶段 2 前不接入旧 Token，避免与既有平台会话混用。
